# Used tools
- **GitHub and Git** are used as the project's source control platform, hosting the repository, managing collaboration, and tracking changes.
- **Poetry** is used as the dependency and packaging manager, ensuring reproducible builds and clean environment setup.
- **Python 3.14** and the standard library is used as the primary language to orchestrate the project's codebase and the application's overall behavior.
- **Flake8** is used to enforce code consistency and style across the Python codebase, following modern PEP 8 standards.
- **PySide6** is used to implement an interactive graphical interface, integrating sound, animations, and advanced multimedia widgets.
- **QSS (Qt Style Sheets)** is used to control the application's visual appearance, applying a structured color palette and style.
- **PyInstaller** is used to package and distribute the application as an executable across multiple operating systems.
- **gettext** is used to support scalable internationalization, enabling the interface to be translated into multiple languages.
# Used architectures and systems
- **Model-View Design Architecture** is used to separate concerns and enable proper application scaling.
- **JSON-based configuration files** are used to provide a highly customizable configuration system, allowing users to intuitively tailor the program's behavior.
- **JSON-based trivia system** is used to create and read trivia content, supporting both distribution and storage of user-generated trivia.
